Preferencias de este navegador.

AcciónTecla · pulsa para cambiarMando

Desactiva la conducción para editar. Una asignación repetida se mueve a la nueva acción. Esc siempre permite parar; las teclas no actúan dentro de campos o diálogos.

En modo WiFi, el ESP8266 confirma las salidas y limita los movimientos con un watchdog local. Esto no confirma desplazamiento físico mediante sensores. El modo de registro solo actualiza la API/RDS; las secuencias DEMO guardadas siguen siendo de software.

Un recorrido para presentar el proyecto

  1. Conexión. Introduce el CONTROL_TOKEN de EC2 y carga el catálogo real.
  2. Administración. Crea un vehículo de prueba, sus comandos y una DEMO con sus pasos.
  3. Movimiento. Envía un comando y muestra cómo cambian el estado y el historial.
  4. Secuencia. Ejecuta una DEMO y observa los eventos; comprueba que no agrega historial.
  5. Peticiones y eventos. Explica el método HTTP, la ruta, el JSON enviado y la respuesta recibida.

El WebSocket transmite eventos de software. Los eventos y el campo conectado no confirman ejecución física del ESP8266. Cancelar una DEMO interrumpe la secuencia de software; no envía una orden física de parada.
